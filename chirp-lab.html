Chirp Lab

A chirped pulse changes its frequency from front to back. Dispersion creates chirp, because each color arrives at its own time. A pulse launched with the opposite chirp is first squeezed and only then spreads: T₁/T₀ = √((1 + C₀z/L_D)² + (z/L_D)²). Set the initial chirp C₀ and launch the pulse.

Gaussian pulse at λ = 1550 nm with field envelope A(0,t) = exp(−(1 + iC₀) t²/(2T₀²)), so the power is exp(−t²/T₀²) and FWHM = 1.665 T₀ whatever C₀ is. C > 0 is an up-chirp: the frequency rises from the front of the pulse to its back, ω(t) − ω₀ = C t/T₁². The fiber adds the phase β₂zΔω²/2 to every frequency; β₂ = −λ²D/(2πc), so D = 17 ps/(nm·km) gives β₂ ≈ −21.7 ps²/km and the blue edge travels ahead. The chirp grows as C(z) = C₀ + (1 + C₀²) β₂z/T₀². The pulse is squeezed first when β₂C₀ < 0. Time is measured in a frame that moves with the group delay. In the top panel the carrier is drawn about 10⁴ times slower than the real 193 THz, and its frequency sweep is exaggerated so that it can be seen; the colors and the time–frequency plane use the true values.
