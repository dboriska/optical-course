Weakly guiding (LP) approximation, valid for small Δ: the modes are solutions of u·Jl−1(u)/Jl(u) = −w·Kl−1(w)/Kl(w), with u² + w² = V² and b = w²/V². Each LP mode group is a set of almost degenerate vector modes, named under each picture (for example LP₁₁ = TE₀₁, TM₀₁, HE₂₁). With a large Δ the vector modes split slightly, as in the mode chart of the lecture. Mode counts include both polarizations and both orientations. Δ = (n₁² − n₂²)/(2n₁²).
