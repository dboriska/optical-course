Two-Fiber Pulse Lab

A Gaussian pulse crosses two fibers in a row, for example standard fiber (SMF) and then dispersion-compensating fiber (DCF). Choose the pulse width and the dispersion and length of each fiber, and watch the pulse broaden in one fiber and narrow in the other. Swap the order of the fibers: the pulse at the end stays the same, but its journey inside the link changes.

Exact solution for a chirped Gaussian pulse at 1550 nm (slides 13–21): with the accumulated ξ = ∫β₂dz, the width is T/T₀ = √[(1 + C₀ξ/T₀²)² + (ξ/T₀²)²] and the chirp is C = C₀ + (1 + C₀²)ξ/T₀² divided by the same factor squared. β₂ = −λ²D/(2πc). C > 0 is an up-chirp (blue trailing edge, red leading edge); the pulse first compresses when β₂C₀ < 0. Only β₂ is included: no loss, no β₃, no nonlinearity. Because each fiber only multiplies the spectrum by a phase, the two orders give exactly the same output pulse; the order matters only for the width and the peak power inside the link, where nonlinearity would start.
